	\section{Практическое применение}
	
	\subsection{openCV}
	В нем есть два метода поиска несоответсвия: 
	\begin{itemize}
		\item stereoBM
		\item stereoSGBM
	\end{itemize}
	
 Принцип работы обоих разберем на stereoBM, так как принцип почти одинаковый, есть бегущая строчка с окном, в котором считывается наилучшее совпадение на левом и правом кадре, и далее уже по этим пикселям  считывает несоответствие и дальше мы получаем карту несоответвествия.
 Использование в коде происходит с помощью команд в кода:
		\begin{lstlisting}
			stereoBM = cv2.StereoBM_create(numDisparities=128, blockSize=25)
			disparityBM = stereoBM.compute(leftImage, rigthImage)
		\end{lstlisting}
		
В первой строчке мы просто создаем объект stereoBM с параметрами, а в следующей строчке мы передаем в этот объект изображение с обоих камер и получаем карту несоответствий. Также у него есть параметры которые можно переделать по надобности.



В коде ниже указано как в дальнейшем имея карту несоответствий перейти к карте глубины
	\begin{lstlisting}
		depthBM = np.zeros(shape=leftImage.shape).astype(``uint8'')
		depthBM[validPixelsBM] = (f * baseline) / 
														 (scale * disparityBM[validPixelsBM])
	\end{lstlisting}
	
Также есть возможность построить тепловую карту.

\subsection{Сравнение методов представленных в OpenCV}

\begin{itemize}
	\item stereoBM

	\begin{itemize}
		\item Плюсы
		\begin{itemize}
			\item Высокая скорость
			\item Простая настройка
			\item Низкие требования к железу
		\end{itemize}
	\end{itemize}
	
	\begin{itemize}
		\item Минусы
		\begin{itemize}
			\item Шумная карта несоответствий
			\item Провалы в однорожддных зонах
			\item Артефакты на границах
			\item Чувстветельность к освещению и калибровке
		\end{itemize}
	\end{itemize}
	
	
	\item stereoSGBM
	
	\begin{itemize}
		\item Плюсы
		\begin{itemize}
			\item Высокая точность
			\item Сохранение границ объектов
			\item Устойчивость к шуму и слабой текстуре
			\item Предсказуемое поведение при правильной настройке
		\end{itemize}
	\end{itemize}
	
	\begin{itemize}
		\item Минусы
		\begin{itemize}
			\item Вычислительно затратный
			\item Больше параметров для точной настройки
			\item Требует более сильное железо
		\end{itemize}
	\end{itemize}
\end{itemize}
