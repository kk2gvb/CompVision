	\section*{openCV}
%	\subsection{Обзор на функции для нахождения несоответсвий и глубины}
	В \texttt{openCV} есть два метода поиска несоответсвия: \texttt{stereoBM} и \texttt{stereoSGBM}.
	
	 Принцип работы обоих алогритмов идентичный. Мы сравниваем каждый кадр по двум кдрам (левой и правой). Кадры разбиваются на строки шириной \texttt{blockSize}, сравнение идет построчно. По строке слева направо двигается окно сравнения, с помощью которго считается наилучшее совпадение объекта на левом и правом кадре. После нахождения совпадения рассчитывается смещение объекта в пикселях, используя формулу, находится расстояние до объекта. Таким образом строится карта несоответствий.
	 
	 Использование в коде происходит с помощью следующих команд:
	 
		\begin{lstlisting}
			stereoBM = cv2.StereoBM_create(numDisparities=128, blockSize=25)
			disparityBM = stereoBM.compute(leftImage, rigthImage)
		\end{lstlisting}
		
	\texttt{StereoBM\_create} создаеt объект \texttt{stereoBM} с параметрами \texttt{numDisparities} и \texttt{blockSize}, далее передаем в созданный объект изображение с обоих камер и получаем карту несоответствий. У объекта есть параметры которые можно настроить для более точной работы.
	
	Ниже показано как из карты несоответствий построить карту глубины.

	\begin{lstlisting}
		depthBM = np.zeros(shape=leftImage.shape).astype(``uint8'')
		depthBM[validPixelsBM] = (f * baseline) / 
														 (scale * disparityBM[validPixelsBM])
	\end{lstlisting}
