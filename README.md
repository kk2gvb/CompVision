# CompVision

Проект исследует методы восстановления глубины по бинокулярным изображениям. В репозитории есть рабочий код для обработки стереовидео, LaTeX-статья, калибровочные данные и результаты экспериментов.

## Структура проекта

- `paper/` — статья по проекту, преамбула LaTeX и графические иллюстрации.
- `code/` — рабочие скрипты для запуска StereoBM, StereoSGBM и StereoSGBM+WLS.
- `code/legacy/` — экспериментальные скрипты из старой структуры.
- `data/calib/` — калибровочные параметры стереокамеры.
- `data/videos/` — исходное видео для демонстрации.
- `data/samples/` — тестовые стереопары для локального сравнения.
- `results/` — выводы и результатирующие артефакты.

## Установка зависимостей

```bash
python3 -m pip install -r requirements.txt
```

## Быстрый запуск

```bash
cd code
python3 run_disparity.py
```

Дополнительные скрипты:

- `python3 stereo_bm.py` — запуск метода StereoBM.
- `python3 stereo_sgbm.py` — запуск метода StereoSGBM.
- `python3 stereo_wls.py` — запуск метода StereoSGBM + WLS.

## LaTeX

Статья хранится в `paper/document.tex`. Компиляция:

```bash
cd paper
pdflatex document.tex
```

## Примечания

- Большие видеофайлы находятся в `data/videos/` и игнорируются Git.
- В `code/legacy/` сохранены прежние экспериментальные версии для анализа.
